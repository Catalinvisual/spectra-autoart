# Spectra AutoArt - Frontend

Frontend React pentru sistemul de programări auto Spectra AutoArt.

## Tehnologii folosite

- React 19 cu TypeScript
- Vite pentru build și development
- React Router pentru navigare
- i18next pentru internaționalizare
- GSAP pentru animații
- Axios pentru API calls

## Structura proiectului

- `src/components/` - Componente React reutilizabile
- `src/pages/` - Paginile aplicației
- `src/services/` - Servicii pentru API și utilități
- `src/styles/` - Stiluri și teme
- `src/locales/` - Fișiere de traducere

## Instalare

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build pentru producție

```bash
npm run build
```
